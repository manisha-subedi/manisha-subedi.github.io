\vspace{2pt}

\noindent\textbf{A warehouse on a laptop} \hfill \href{https://github.com/manisha-subedi/laptop-warehouse}{\textcolor{linkblue}{Link to project}}
\begin{itemize}
    \item Loads monthly Chicago bike-share files into DuckDB and cleans the data with dbt. The loader processed 2.3 million real rides in 25 seconds.
    \item Uses file hashes to identify files that have already been loaded. A dbt test fails the build when a file has twice or half the usual number of rows.
\end{itemize}

\vspace{2pt}

\noindent\textbf{Late deliveries and bad reviews} \hfill \href{https://github.com/manisha-subedi/late-deliveries}{\textcolor{linkblue}{Link to project}}
\begin{itemize}
    \item Analysed 96,470 real orders from a Brazilian marketplace using SQL and DuckDB. Late deliveries made up 7\% of orders and 37\% of one-star reviews.
    \item The results pointed to promised delivery dates in some states and months rather than the sellers. In the analysis, adding three days to the promised date lowered the late-order rate from 6.8\% to 4.8\%.
\end{itemize}
