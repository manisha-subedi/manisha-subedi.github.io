An A/B test records a click rate of 50 percent for button A and 55 percent for
button B, with 200 users on each button. The observed difference is 5
percentage points. These figures alone are not enough to conclude that button
B is better because measured rates vary from sample to sample.

The ball simulation below shows that variation. The later calculation is a
simplified approximation. It explains the main relationship between sample
size and uncertainty, but it does not replace a formal sample-size
calculation.

The box starts with 20 balls. Neither side is favoured, so the expected share
in the shaded half is 50 percent. With only 20 balls, the counter may show
values such as 45, 60, or 35 percent.

Select "500 balls". The counter varies less and usually remains between 47 and
53 percent.

The movement of the balls has not changed. Only the number being counted has
changed. A larger count produces less sampling variation.

## 1. Approximate variation in a measured share

For a measured share, the approximate standard error is
sqrt(p(1−p)/n), where p is the true share and n is the count. For p = 0.5,
p(1−p) is 0.25.

- 20 balls: sqrt(0.25 / 20) = 0.11, or about 11 percentage points.
- 200 balls: sqrt(0.25 / 200) = 0.035, or about 3.5 percentage points.
- 2,000 balls: about 1.1 percentage points.

Increasing the count by ten times reduces the variation to about one third.
This square-root relationship is why large samples are often needed.

## 2. Compare the difference with its sampling variation

Return to the A/B test. With 200 users on each button, each measured click
rate has an approximate standard error of 3.5 percentage points. The
difference between two independent measured rates varies more. Its standard
error is about 1.4 times larger, or about 5 percentage points.

The observed difference is also 5 percentage points. If the two buttons have
the same true click rate, button A can still lead by at least 5 points about
one time in six. The simulation below checks this result.

```python
import random

def share(n, p=0.5):
    return sum(random.random() < p for _ in range(n)) / n

# 1,000 A/B tests where the two buttons are exactly the same
wins = sum(share(200) - share(200) >= 0.05 for _ in range(1000))
print(wins / 1000)    # about 0.16
```

In about one test in six, the first measured rate is at least 5 points above
the second even though both true rates are 50 percent. An observed result of
55 percent versus 50 percent is therefore possible when the buttons have the
same true rate.

## 3. A simplified sample-size approximation

Suppose the effect of interest is d. For this explanation, require the
standard error of the difference to be one third of d. This is a teaching
approximation, not a general sample-size rule.

For two equal groups, the approximate standard error of the difference is
sqrt(2 · p(1−p) / n). Set it equal to d/3 and solve for n:

n = 18 · p(1−p) / d²

For p = 0.5 and a 5 point effect, this gives
18 × 0.25 / 0.0025 = 1,800 users per button. It does not give 200.

```python
def users_per_arm(p, d):
    return 18 * p * (1 - p) / d**2

users_per_arm(0.5, 0.05)   # 1800
users_per_arm(0.5, 0.02)   # 11250, a 2 point effect is expensive
```

A common textbook approximation uses 16 instead of 18 because it sets the
thresholds more carefully for a 5 percent false-alarm rate and 80 percent
power. Both versions have the same basic form. The calculation here is only a
simple derivation of that form.

## Use the approximation carefully

Sampling variation matters whenever a share is based on a small count. One
country may have only 30 visitors in a conversion report. One supplier may
have shipped only 12 parts in a defect report. Rankings of the
"best-performing" advertisement, store, or day of the week can also place
small groups at the extremes because small groups vary more.

As a rough check, calculate sqrt(p(1−p)/n) for the smaller group before
comparing two shares. If the difference is not at least two or three times
this value, treat the result as uncertain. This check is still an
approximation, not a formal test or power calculation.

In the opening example, the 5 point difference with 200 users per button is
about the same size as the approximate standard error of the difference. That
is not strong evidence that button B has a higher true click rate.
