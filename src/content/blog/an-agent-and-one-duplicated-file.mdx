People talk about AI agents like they are magic. They are not. An agent is a
loop. It looks at something, it does something, and it checks the result.
Then it does it again. This post shows one loop from start to end. The data
is made up, but the problem is real.

The question is simple. What was the revenue in August? The warehouse has
three tables and one problem. The August order file was loaded two times.

Scroll through the seven steps. The picture at the top changes with each

## The step that matters

Every step in the loop is ordinary. The important one is step four. Without
that check, the agent returns 84,000 with full confidence, and the number
goes into a presentation. With the check, the agent finds the problem and
reports it.

Two things to learn from this. First, an agent needs a way to check its own
result. A row count, a comparison with last month, a known total. Second, an
agent should not change data on its own. Here it only leaves the second copy
out of the calculation, and it says so. Fixing the load is a job for a person
with permission.

The steps on this page are written by hand. No model runs on this site. In a
real system the loop is the same, only slower and with more mistakes on the
way.
